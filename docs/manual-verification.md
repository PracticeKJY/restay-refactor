# 수동 회귀 검증

현재 브라우저 자동화가 불가능하므로 아래 항목은 **미검증**이다. 자동 테스트의 mock/SSR 검증과 실제 사용자 흐름은 구분한다.

## 실행
1. Node 22.17.0 기준 `npm run build`.
2. `npm run start -- --hostname localhost --port 3101`.
3. 브라우저에서 `http://localhost:3101` 접속. 로컬 바인딩과 접속 hostname을 일치시킨다.
4. 기존 정상 동작 환경의 인증 설정을 이용한다. 현재 Codex의 로컬 production에서는 NextAuth `UntrustedHost`가 발생한다. 이를 피하기 위한 환경변수·인증 정책 변경은 수행하지 않았다.
5. DB 쓰기가 필요한 검증은 별도 테스트 환경·테스트 계정에서만 진행한다. 실제 결제는 실행하지 않는다.

## 화면 크기
320, 375, 768, 1024, 1280, 1440px에서 한국어/영어를 비교한다. 기존 데스크톱 화면과 카드 위치·간격·색·타이포그래피·갤러리·예약 위젯을 비교한다. Home grid의 기존 CSS는 수정하지 않았다.

정적 규칙 검사: 320/375/768/1024/1440px의 CSS cascade 테스트는 통과했다. 아래 브라우저 항목은 여전히 미검증이다.

| 화면 | 320 | 375 | 768 | 1024 | 1440 |
|---|---|---|---|---|---|
| Navbar/검색/언어 선택 | [ ] | [ ] | [ ] | [ ] | [ ] |
| 공통 모달/호스팅 폼 | [ ] | [ ] | [ ] | [ ] | [ ] |
| 숙소 상세/갤러리/지도 | [ ] | [ ] | [ ] | [ ] | [ ] |

각 칸은 한국어·영어 모두 확인 후 체크한다. 실제 화면에서 `document.documentElement.scrollWidth <= window.innerWidth`를 확인하고, 의도된 카테고리 가로 탐색은 페이지 전체 overflow와 구분한다.

## 언어와 탐색
- `/`·`/en`, `/listings/{id}`·`/en/listings/{id}` 직접 진입.
- 영어 쿠키/브라우저에서도 접두사 없는 URL이 한국어인지 확인.
- 상세·예약·위시리스트·여행·메시지에서 언어 변경 시 ID/query/hash 보존.
- `/?category=빌라` ↔ `/en?category=빌라`: 표시 라벨만 영어, 실제 필터 값은 한국어 유지.
- 뒤로/앞으로·새로고침·언어 변경 후 세션, 선택 날짜, 하트 상태 확인.
- OAuth 후 기존 `/` 복귀는 유지했다. 영어 OAuth 완료 후 한국어 홈으로 복귀할 수 있다.
- 저장된 숙소 제목·설명·주소·이름·채팅 원문은 번역하지 않는다.

## 화면/접근성
- Navbar의 언어 선택·사용자 메뉴·검색·추천어를 키보드로 사용.
- 모달 열기 → 첫 컨트롤 포커스 → Tab/Shift+Tab 순환 → Escape/닫기 → 시작 요소 포커스 복귀. 입력 중 포커스가 튀지 않는지 확인.
- 모달·호스팅 폼에서 작은 높이/모바일 키보드가 있어도 마지막 버튼까지 스크롤 가능.
- 상세 갤러리의 화살표/스와이프·키보드 숙소 링크·지도 로딩/로드뷰.
- 예약 날짜 선택·수정, 같은 날짜의 한국어/영어 KRW 합계 일치. 날짜 계산·결제 payload는 변경하지 않았다.
- 위시리스트·여행의 긴 제목, 카드 이미지와 예약일 줄바꿈.
- 메시지의 긴 이메일/URL/문장, 채팅 입력 폭·키보드·전송·실시간 수신. Supabase 정책/초기화 코드는 기존 그대로다.
- 시각적 페이지 가로 넘침 여부를 확인. 세로 스크롤이나 카테고리의 의도된 가로 탐색과 구분한다.
